A short fact about the thing it sits on. A plain chip states a property; a chip with `data-tone` states a category.

Provide two or three words. Set `data-tone` to `red`, `blue`, `violet`, `green` or `amber` only where the hue already means that category elsewhere on the site.

- Chips are not buttons. If it can be pressed, it is a button.
- Group chips in a `chips` row. Three or four is plenty.
- In Line Map, toned chips become solid route bullets. In Internet-Draft they are bracketed tags.
