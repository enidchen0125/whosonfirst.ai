An action or a link that deserves to look like one. Three weights: `btn primary`, `btn`, and `btn ghost`; add `small` inside a toolbar.

Provide a label that says what happens: “Explore the flows”, never “Click here”. Use an `a` for navigation and a `button` for an action on the page.

- One primary button per view. It takes `accent` with `on-accent`.
- Ghost buttons are for tertiary actions and toggles.
- In Internet-Draft, buttons are drawn as bracketed text and the primary is an inverse block.
