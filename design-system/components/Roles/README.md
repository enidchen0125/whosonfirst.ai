The five kinds of participant, and the hue each one keeps everywhere.

Put `role-human`, `role-agent`, `role-authz`, `role-resource` or `role-infra` on a container. It sets `--role` and `--role-soft` for everything inside: outline in `--role`, fill in `--role-soft`, text in `fg`.

- A participant’s role decides its colour. Nothing else does.
- Human is `red`, agent is `blue`, authorization is `violet`, resource is `green`, infrastructure is `amber`.
- Always label a role in words as well.
