A link to one thing, shown among its peers. The whole card is the target.

Provide a heading, one sentence, and optionally a row of chips. Wrap the card in an `a`; do not put other links inside it.

- Use cards for a set of like things: flows, standards, deployment guides.
- Do not use a card for emphasis. A paragraph does not become more important by getting a border.
- Cards sit on `bg-raised` with a `border` hairline. Hover is the only state.
